# Pharmexia v2.1.0 analytical verification package

Contents
- `oncox.py`  v2.1.0 = v2.0.0 + strand-aware matching (v2.0.1) + CYP2C19*4 locus rs28399504 (v2.1.0). `v2.0.0_to_v2.1.0.patch` is the full diff; `strand_aware_matching.patch` is the v2.0.1 step only.
- `data/star_allele_rules.json`  rule file used for the verification (generated by `build_rules.py` from PharmCAT v3.4.0 phenotype tables). Compare it with the rule file in your local project before publishing; if they differ, re-run everything with yours.
- `benchmark.py`  scenarios A-D (350 scenarios: 123 + 216 + 11) and allele-catalogue coverage (scenario B, 113 annotated alleles)
- `strand_test.py`  scenario E (forward-strand vs coding-strand input for TPMT and VKORC1)
- `make_tests.py`  writes the eight synthetic VCF files and one CSV, and runs them end to end
- `fig5.py`  redraws Figure 5 from the result files
- `test_files_v210/`  S01-S08 VCF files and S02 CSV (with REF and ALT columns)
- `results/`  per-scenario output for v2.0.1 and v2.1.0

Reproduce
1. `git clone --depth 1 https://github.com/PharmGKB/PharmCAT` and set `PC` in `build_rules.py`, `benchmark.py` and `make_tests.py` to its `src/main/resources/org/pharmgkb/pharmcat` folder.
2. `python build_rules.py`
3. `PGX_MODULE=oncox python benchmark.py`, then `PGX_MODULE=oncox python strand_test.py` and `PGX_MODULE=oncox python make_tests.py`

`stubs.py` replaces PySide6, FastAPI and uvicorn with mocks so the engine runs headless. Running `strand_test.py` against unpatched v2.0.0 gives 28 of 30 discordant combinations.
Expected on v2.1.0: 0 discordant in scenarios A, C, D and E; 96 of 96 undetectable alleles inconclusive; 13 concordant and 4 inconclusive-by-design among the 17 detectable alleles.
The reference is PharmCAT v3.4.0 data tables, not PharmCAT program output.
